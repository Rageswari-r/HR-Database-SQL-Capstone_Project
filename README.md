# HR-Database-SQL-Capstone_Project
## Project Overview
An end-to-end SQL project focused on HR data management, relational database concepts, and real-world business queries.
This project uses an HR-style relational database to manage and analyze employee, department, job, salary, location, country, region, and job history data.
The project demonstrates practical Oracle SQL skills through database setup, data management, table relationships, and business-oriented data analysis.

--------------------------------------------------------------------------------------------------------------------------------------

## Objectives
- Build and manage an HR-style relational database using Oracle SQL
- Understand relationships between multiple database tables
- Practice SQL using real-world HR and business scenarios
- Analyze employee, salary, department, and job data
- Develop SQL problem-solving and analytical skills
- Apply SQL concepts to practical business problems
- Prepare for SQL technical interviews

--------------------------------------------------------------------------------------------------------------------------------------

## Dataset / Database
The project uses an HR-style relational database containing employee and organizational data.
The database consists of 8 tables:
- 'REGIONS' – Stores geographical region information
- 'COUNTRIES' – Stores countries and their associated regions
- 'LOCATIONS' – Stores office and workplace locations
- 'DEPARTMENTS' – Stores department information and managers
- 'JOBS – Stores job titles and salary ranges
- 'EMPLOYEES' – Stores employee details, salaries, managers, jobs, and departments
- 'JOB_HISTORY' – Stores employees' previous job and department history
- 'JOB_GRADES' – Stores salary ranges and corresponding grade levels
The project also includes 100 SQL practice and business-oriented questions covering different levels of SQL analysis.
